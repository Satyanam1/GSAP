# GSAP Learning Journey

This repo is where i'm documenting my journey learning **GSAP (GreenSock Animation Platform)** - a JavaScript library for creating high-performance animations on the web.

## What is GSAP?
GSAP lets you animate almost anything (CSS properties, SVG, canvas, React components, etc.)
with smooth, high-performance, cross-browser animations — way more powerful than plain CSS transitions.

## Topics Covered So Far
- Basic tweens (gsap.to, gsap.from, gsap.fromTo)
- ScrollTrigger plugin(trigger, scroller, scrub, pin)
- SVG Animations
- Custom Cursor
